# DuckDB Virtual Server Example

[Live demo](https://perspective-dev.github.io/examples/esbuild-duckdb-virtual/)

A `<perspective-viewer>` backed by
[DuckDB-WASM](https://duckdb.org/docs/api/wasm/overview) through a
`VirtualServer`, all in the browser, bundled with
[`esbuild`](https://esbuild.github.io/).
